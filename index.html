Borland Turbo C++ Essential Shortcuts

Shortcut Function Description
Ctrl + F9 Run Program Compiles, links, and runs the active program.
Alt + F5 User Screen Switches to the output console to view program results.
F5 Zoom Window Maximizes or restores the current active editor window.
F2 Save File Saves the currently open source code file.
F3 Open File Opens an existing .C or .CPP file from the virtual disk.
Shift + Insert Paste Modal Opens the browser live code insertion dialog.
Alt + X Quit Turbo C++ Exits the Borland IDE environment.

❓ Frequently Asked Questions (FAQ)

How do I paste code into Turbo C++ without typing?
Click the Paste Code (for mobile users) button at the top (or press Shift+Insert / Ctrl+Shift+V). Paste your C or C++ code into the box, choose a target filename (e.g., CODE.CPP), and click Insert into Turbo C++. The code will be saved directly into the DOS filesystem and loaded into the editor in under 0.3 seconds.
Can I upload my existing .C or .CPP project files?
Yes! Click the Import (.CPP) button in the toolbar, or simply drag and drop your source file anywhere onto the emulator window. Your code will load into the injection dialog ready to run.
Does this compiler support graphics.h and BGI?
Yes, full EGA/VGA graphic modes via <graphics.h> and initgraph(&gd, &gm, "C:\\TURBOC3\\BGI"); are supported. All shapes, circles, lines, and custom palettes render accurately inside the browser canvas.
How do I view program output screen?
Press Alt + F5 on your keyboard or tap the Output (Alt+F5) button on the mobile toolbar. You can also place getch(); right before return 0; in your main() function.
How do I use this on Android or iPhone?
Our online compiler includes a mobile-optimized touch bar located directly beneath the screen. Tap Keyboard to bring up your phone's virtual keyboard, and use the dedicated buttons for Run, Output, Save, and Zoom.
How do I run a ready-made program in Turbo C++ online?
Open the Ready-made Programs panel, select C or C++, and tap a program. It loads into Turbo C++ with its file name. Press the Run (Ctrl+F9) button, then Output (Alt+F5) to see the result.
How do I save, download or clear my code?
Tap Save to keep the code in My Saved Programs, Download to get it as a file, and Clear to wipe the editor in one tap. All three work on whatever is in the editor, including unnamed NONAME00.CPP files.
